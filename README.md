# 下班工具箱 - EduAssist

## 📋 写在前面

**致汝州一高的老师们：**

您们的核心价值在于传道授业与启发思考，而非深陷于繁杂重复的事务性工作。**下班工具箱（EduAssist）**
是专为我校教师开发的数字助手，旨在将老师们从耗时费力的重复性任务中解放出来，**增加宝贵的休息时间**。

---

## ✨ 核心功能

| 功能模块 | 适用角色 | 说明 |
|:--------|:--------|:-----|
| **📚 自动刷课** | 全体教师 | 自动完成教师再教育课程的视频播放、章节切换，释放业余时间 |
| **📅 辅助排课** | 业务部长（Pro 版） | 输入自然语言排课需求 → AI 生成排课建议 JSON → 本地可视化调整 |
| **💰 津贴计算** | 业务部长（Pro 版） | 基于排好的课表自动统计任意日期区间内各教师的实际课时数 |
| **📈 成绩分析** | 全体教师 | 快速导入成绩 Excel，自动统计均值、排名、通过率、分段人数，生成直方图 |
| **🗂️ PDF 工具箱** | 全体教师 | 合并、拆分、旋转、压缩 PDF，方便教学材料整理与分发 |

### 版本说明

只打**一份安装包**，通过前端功能开关区分：

| 版本 | 适用 | 功能 |
|:----|:----|:-----|
| **普通版** | 全体教师 | 刷课、成绩分析、PDF 工具箱 |
| **Pro 版** | 班主任 / 业务部长 | 普通版全部 + 辅助排课 + 津贴计算 |

---

## 🚀 技术特色

- **🖥️ 轻量桌面应用**：基于 Tauri + Vue 3 开发，利用系统 WebView，安装包小、内存占用低，能在 7 年前办公电脑（4GB 内存、机械硬盘）上流畅运行。
- **🔒 本地优先**：核心数据运算均在您本机完成，不经过任何外部服务器。仅 AI 辅助排课和反馈提交需要联网。
- **📦 开箱即用**：下载安装包 → 下一步 → 完成，无需任何配置即可使用。

---

## 📦 获取与开始使用

1. **下载安装**：前往 [Releases](https://github.com/rzyg/EduAssist/releases) 页面下载最新安装包（`.exe`）。
2. **安装运行**：像安装其他软件一样完成安装，双击桌面图标即可使用。
3. **系统要求**：Windows 10 及以上，推荐 64 位系统；4 GB 以上内存；机械硬盘或 SSD 均可。

---

## 🛠️ 技术栈

```
前端：Vue 3 + TypeScript（运行于系统 WebView）
桌面壳：Tauri 2.0（Rust）
核心引擎：Python FastAPI（Nuitka 编译为单 exe）
依赖库：Playwright / pypdf / pdfplumber / pikepdf / pandas / openpyxl / matplotlib
云端（极简）：FastAPI + SQLite（AI 代理 + 设备 UUID 限流 + 反馈收集）
```
